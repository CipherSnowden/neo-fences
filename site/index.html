NeoFences
Guide GitHub

Your desktop, in fences.

Translucent fences hold links to your apps, games, files, folders and websites — never the files themselves. Widgets, live folder panels, game covers, and a desktop that stays tidy. Built for a gaming PC first.

Download for Windows 11 Free · 64-bit · release notes

Games as covers

Steam, Epic, GOG, Ubisoft, EA, Battle.net, Xbox and your own game folders — found and shown as covers, next to your apps.

Widgets

A clock, the date, and CPU, GPU, RAM and temperatures — in any fence, at any size.

Live folder panels

Downloads, a game folder or a USB stick shown live inside a fence, as details, a list or icons.

Peek and the keyboard

Ctrl+Alt+Space brings the fences above your windows with the keyboard in one: arrows, Enter, Tab to the next fence, Esc back to your app.

Quiet while you play

A full-screen game puts NeoFences to sleep: no timers, no network, about 0 % CPU until you are back.

Your files are safe

Fences hold links: removing one never touches a file. Hidden desktop icons always come back — after a crash too. Snapshots and an undo for everything else.

Install in a minute

  1. Download the installer and run it. No administrator rights needed.
  2. If Windows says "Windows protected your PC", click More info → Run anyway. NeoFences is unsigned, not unsafe: a signing certificate costs money every year. Every download can be checked instead.
  3. If Smart App Control blocks it, that Windows feature allows only signed apps; turning it off is your decision — read Microsoft's FAQ first.

NeoFences updates itself. No telemetry, no accounts, no ads — privacy.
