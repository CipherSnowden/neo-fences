NeoFences

A Fences-style desktop organizer for Windows 10/11 x64. Translucent fences that hold links to your files, folders, apps and websites, each with its own name and icon, with live acrylic blur over Wallpaper Engine and zero overhead while you game. Your files never move.

Project description

What NeoFences is

The idea

Your desktop gets a set of fences: acrylic panels that group things you open often ("Games", "Work", "Links"). A fence holds virtual items: links with their own name and icon that point at a file, folder, app or website. Dropping something on a fence adds a link; removing it, or the whole fence, never touches the file (ADR-040).

Your native desktop icons stay as Windows shows them, unless you switch on "Hide desktop icons while NeoFences runs". Links follow renamed files, dim when a drive is unplugged, and offer Locate… when a target goes missing.

Built for one power user first: a developer and story-game player running Wallpaper Engine on a Windows 11 gaming rig.

Priorities, in order

  1. Robust and reliable. Never touch your files, never leave the desktop blank.
  2. Modern UI/UX. Fluent, acrylic, light/dark, smooth but optional animation.
  3. Decent performance. ~0% CPU idle, fully idle during games.
  4. Feature count. Fences 5/6 parity, then extras.

    Shift+right-click: Windows' menu

    Title bar

    Drag to move. Double-click to roll up. Rolled-up fences show a count and expand on hover (300 ms) or click. Right-click the title or empty space for the fence menu: Add item…, Refresh, Sort by, Icon size, Lock, Delete fence.

    Items

    Each item shows its own name and icon (from the target, an .ico/.exe/.dll, or a picture). A missing target is dimmed with a warning badge; an unplugged drive or unreachable share is dimmed. Enter opens, F2 or Alt+Enter opens Properties, Del removes the item.

    Menus

    The item menu above never touches the file. Windows' full menu (7-Zip, Open with, Send to) is behind Shift+right-click, under a grey line saying it acts on the real file. Delete fence asks first and never deletes files.

    ADR-006 · ADR-041

    Data model

    Two JSON files in %LOCALAPPDATA%\NeoFences\: config.json (fences, settings, layouts; schema 5) and items.json (the virtual items, one list per fence). Both are saved atomically with a .bak and 10 daily backups, config first. Beside them: icons\ (pictures chosen as item icons), snapshots\ and library\ (the Game Library's shortcuts).

    config.json (example)

    {
  "schemaVersion": 5,
  "settings": { "hideDesktopIcons": false,
                "peekHotkey": "Ctrl+Alt+Space",
                "startWithWindows": true },
  "fences": [
    { "id": "a1f3…", "title": "Games", "iconSize": 48,
      "rolledUp": false, "tabs": ["a1f3…", "d5e6…"] },
    { "id": "d5e6…", "title": "Links" },
    { "id": "c9d4…", "title": "Library", "isLibrary": true }
  ],
  "library": { "folders": ["D:\\GameLibrary"] },
  "layouts": {
    "<display fingerprint>": { "fences": {
      "a1f3…": { "monitor": "<device id>",
                 "x": 40, "y": 60, "w": 420, "h": 260 } } }
  }
}

    items.json (example)

    {
  "schema": 1,
  "fences": {
    "a1f3…": [
      { "id": "7e21…", "target": "D:\\Games\\Crysis 2\\Crysis2.exe",
        "name": "Crysis 2", "arguments": "-dx11" },
      { "id": "90bc…", "target": "::{645FF040-5081-101B-9F08-00AA002F954E}" }
    ],
    "d5e6…": [
      { "id": "4f0a…", "target": "https://github.com",
        "icon": { "image": "4f0a…-1c2d.png" }, "note": "work repos" }
    ]
  }

    When a target changes

    EventThe item
    Target renamed (or its folder renamed)Follows the new path, in every fence
    Target deletedStays, shown Missing; opening it offers Locate… or Remove
    Drive unplugged, share unreachableStays, shown Unavailable; back to normal when the drive returns
    Changed while NeoFences was offChecked at start; items are never dropped by themselves
    Corrupt config or items fileTry .bak, then newest backup, then fresh; corrupt file kept
    File from a newer NeoFencesRead-only: never rewritten by an older version
