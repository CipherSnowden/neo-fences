# M28 — Polish (0.16.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The 20 minors the M24–M27 reviews deferred — folder panels, auto-collect, widgets, grid and sizes — as one patch release, with no new features or settings.

**Architecture:** Core gets the decisions it can make (Details columns by width, unknown widget kinds, GPU per adapter, the culture's year-month, the drag anchor, a fence's columns for its width, the common size of a selection). The App gets the rest: widget and panel controls built only where used, the input and menu fixes, the auto-collect timing fixes, widget freshness, the Size picker by keyboard, cover-width cells, one placement per drop.

**Tech Stack:** .NET 10, WPF, CsWin32 0.3.335 (no new bindings), xUnit, Serilog, Velopack (unchanged).

**Spec:** `docs/superpowers/specs/2026-10-05-polish-design.md` (approved 2026-10-05). No new ADR (ADR-047 amended for unknown widget kinds). Build notes: `docs/research/m28-polish.md` (added by Task 3).

## How this plan is written

Every change was built in a scratch prototype first (2026-10-05, worktree `neo_fences-m28proto`, branch `m28-proto`). A
visual probe on a copy of the user's data caught one bug of the template change (the content holder printed the item's
type name under plain icons; fixed by collapsing it unless the element is a widget or a panel) and then showed the clock,
stats, an "Unknown widget" with the Missing badge and a narrow Details panel with Name and Date. Each task's patch was
replayed on a fresh worktree of `main` at `676f00d`: the Core tests failed to compile before the Core patch
(`CS0117: 'Widgets' does not contain a definition for 'IsUnknown'`) and passed after it (643), the solution built with 0
warnings after the App patch, and the replayed tree is identical to the prototype. So each code step is **a patch to
apply**:

1. Write the patch block **exactly** as shown to a file in the scratchpad (use the Write tool, never a shell heredoc).
   The file ends with one newline.
2. `git apply --whitespace=nowarn <file>` from the worktree root. If it does not apply, stop (rule on it, never
   hand-merge silently).

## Where the build departs from the spec (decided while prototyping; the final review weighs them)

- **A4**: a batch that adds items saves items.json before config.json (a power cut in between collects the batch again,
  never skips it) instead of stamping the watermark with the listing's time.
- **G5**: icon-only fences that show game covers get cells as wide as a cover (all their cells).
- **G6** is an App change (one placement for every arrival of a drop); Core already placed path arrivals at the drop cell.
- **W4**: an unknown widget is `ItemKind.Widget` (never opened through Windows), named "Unknown widget", shown Missing, as
  an item with the widget menu.
- **W1**: after a hidden spell longer than 4 s a first stats reading only primes; the shown one comes 2 s later.

## Global Constraints

- Hard rules stand: no file is touched; Win32 only in NeoFences.Shell via **CsWin32**; **no new NuGet dependency**;
  failures degrade one feature, never crash.
- No new features, settings or UI copy beyond: "Unknown widget", "Mixed sizes", "A widget.", and the Size picker's name
  "Size: arrow keys choose, Enter sets".
- Details columns: Name and Date below **300 DIP**, all four from there.
- Commits: single line, Conventional Commits, past tense, **no Co-Authored-By trailer**.
- Version stays `0.16.0` until the release step; the release is 0.16.1.

## Review Focus

1. **The template change (P4)**: every element kind still renders — icons, covers, widgets (each kind, each size), panels
   (each look, Fill), missing and unavailable states, labels on hover — and selection, hover, drag and the hover name work
   as before.
2. **Unknown widget kinds (W4)**: Properties, Size ▸, Remove, drag, copy, snapshot, the bulk fix and target checks never
   treat `neofences:widget/…` as a file; nothing passes it to the shell.
3. **The Size picker by keyboard (G4)**: arrow keys at the edges, Enter, Esc, the mouse after the keyboard, a selection of
   mixed sizes, "Default size".
4. **Drops (G1, G6)**: Move and Ctrl-copy in Free and Flow fences, a drag whose pressed element is not selected first, a
   drop mixing items and paths, a drop of paths only, an already-held path.
5. **Auto-collect timing (A1–A4)**: the offer when the listing fails, the dialog cancelled, a fence deleted meanwhile, a
   game starting while a lister is new.
