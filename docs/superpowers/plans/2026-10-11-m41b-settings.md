# M41b Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Settings a friend understands: the look of a fence set in one window (This fence | All fences) with a live
preview and explanations, a Settings window with pages and search, recipes instead of presets, the audit's removals
and wording fixes, and the rc.3 leftovers — released as 1.0.0-rc.4.

**Architecture:** Core grows the all-fences defaults (AppearanceSettings), nullable per-fence icon size and labels that
follow them, a one-time migration, `AllFences` helpers (own / follows / make follow), `Recipes` (replacing
`LookPresets`) and a `SettingsCatalog` (labels, explanations, search). `FenceLook.Resolve` keeps deciding everything a
fence shows and now also returns its icon size and labels. The App rewrites `FenceSettingsWindow` (v4) and
`SettingsWindow` (v2) on top of those and trims menus. No schema bump: every new field is optional, null fields are not
written (`WhenWritingNull`), and old fields stay readable.

**Tech Stack:** C# / .NET 10, WPF (`net10.0-windows10.0.22621.0`), xUnit; CsWin32 in Shell; VM checks in PowerShell
(`tools/vm`).

**Spec:** `docs/superpowers/specs/2026-10-11-m41b-settings-design.md`

## Global Constraints

- Hard rules (CLAUDE.md): never modify user files; desktop icons always come back; only the `WH_MOUSE_LL` hook; Win32/COM
  only in `NeoFences.Shell`; no new NuGet dependency; Core test-first; failures logged, never a crash.
- A setting or recipe never touches items (items.json), files, or a fence's place or size.
- GUIDE.md changes with every setting, menu entry and gesture (ADR-050); README quick start checked.
- Commits: single line, Conventional Commits, past tense, no Co-Authored-By trailer; secret scan
  (`gmail|claude\.ai/artifact`) before each commit.
- Version stays `1.0.0-rc.3` until the release step; the release is 1.0.0-rc.4 (push, tag, publish only with the
  owner's go).
- Guest VM scripts: ASCII only, parse-checked; live checks in the Hyper-V VMs, not on the owner's PC.
- Edits to existing files: exact-string replacements (scratchpad `rep.js`), never sed on C#.

## Review Focus

1. **An existing setup after the update** (fences with own icon sizes and labels, own looks, own presets, Classic theme,
   light and dark mode): every fence looks exactly as before; nothing jumps or resizes. (Task 1 migration tests; Task 6
   VM check `upgrade-looks-same`.)
2. **All fences mode with fences that have their own values**: changing the all-fences theme changes only following
   fences; "Make them follow" changes exactly the counted fences. (Task 1 tests; Task 6 VM check.)
3. **Recipes on fences with tabs, a library fence, a widget board, a Free layout**: places, sizes, items, tabs and free
   cells stay; only look and behaviour change; Undo / snapshot brings back the exact look. (Task 2 tests.)
4. **The Fence settings window while its fence changes elsewhere** (renamed from the title, deleted, a snapshot
   restored, a tab switched): the window follows or closes, never shows stale values or crashes. (Task 4 by hand +
   checklist BA7.)
5. **Search with odd input** (empty, spaces, one letter, "double", accents, an emoji): never throws, empty query shows
   nothing extra, results stable. (Task 3 tests.)

using NeoFences.Core.Config;

namespace NeoFences.Core.Model;

/// <summary>M41b: the settings a fence can have its own value for, or follow from All fences (spec §1).</summary>
public enum LookSetting { Theme, Transparency, ColourStyle, TitleStyle, TitleFont, TitleAlign, TitleBar, IconSize, Labels, Spacing, OpenWith }

/// <summary>M41b (spec §1, ADR-067): own values and All fences. Pure; each returns a new config or fence.</summary>
public static class AllFences
{
    public static bool HasOwn(Fence fence, LookSetting setting) => setting switch
    {
        LookSetting.IconSize => fence.IconSize is not null,
        LookSetting.Labels => fence.Labels is not null,
        LookSetting.OpenWith => fence.OpenWith is not null,
        _ => fence.Look is { } look && setting switch
        {
            LookSetting.Theme => look.Theme is not null,
            LookSetting.Transparency => look.Strength is not null,
            LookSetting.ColourStyle => look.ColourStyle is not null,
            LookSetting.TitleStyle => look.TitleStyle is not null,
            LookSetting.TitleFont => look.TitleFont is not null,
            LookSetting.TitleAlign => look.TitleAlign is not null,
            LookSetting.TitleBar => look.TitleOnHover is not null,
            _ => look.Spacing is not null,
        },
    };

    public static Fence ClearOwn(Fence fence, LookSetting setting) => setting switch
    {
        LookSetting.IconSize => fence with { IconSize = null },
        LookSetting.Labels => fence with { Labels = null },
        LookSetting.OpenWith => fence with { OpenWith = null },
        _ when fence.Look is not { } look => fence,
        _ => fence with
        {
            Look = ConfigNormalizer.NormalizeLook(setting switch
            {
                LookSetting.Theme => look with { Theme = null },
                LookSetting.Transparency => look with { Strength = null },
                LookSetting.ColourStyle => look with { ColourStyle = null },
                LookSetting.TitleStyle => look with { TitleStyle = null },
                LookSetting.TitleFont => look with { TitleFont = null },
                LookSetting.TitleAlign => look with { TitleAlign = null },
                LookSetting.TitleBar => look with { TitleOnHover = null },
                _ => look with { Spacing = null },
            }),
        },
    };

    public static int OwnCount(NeoFencesConfig config, LookSetting setting) => config.Fences.Count(fence => HasOwn(fence, setting));

    /// <summary>"Make them follow": every fence's own value for this setting goes.</summary>
    public static NeoFencesConfig MakeFollow(NeoFencesConfig config, LookSetting setting) =>
        config with { Fences = config.Fences.Select(fence => HasOwn(fence, setting) ? ClearOwn(fence, setting) : fence).ToList() };

    /// <summary>"Use all defaults": every own value goes; emoji, colour, layout, lock and the rest are only the fence's.</summary>
    public static NeoFencesConfig UseAllDefaults(NeoFencesConfig config, string fenceId) =>
        config with { Fences = config.Fences.Select(fence => fence.Id == fenceId ? Enum.GetValues<LookSetting>().Aggregate(fence, ClearOwn) : fence).ToList() };

    /// <summary>
    /// Once, for a setup from before rc.4: All fences' icon size and labels become the most common among the fences (a tie
    /// prefers 48 and Always: the usual look); a fence with exactly those values follows, others keep them as their own.
    /// </summary>
    public static NeoFencesConfig Introduce(NeoFencesConfig config)
    {
        if (config.Settings.AllFencesIntroduced) return config;
        var sizes = config.Fences.Select(fence => fence.IconSize).OfType<int>().ToList();
        var labels = config.Fences.Select(fence => fence.Labels).OfType<LabelMode>().ToList();
        var size = sizes.Count == 0 ? 48 : sizes.GroupBy(value => value).OrderByDescending(group => group.Count()).ThenByDescending(group => group.Key == 48).First().Key;
        var label = labels.Count == 0 ? config.Settings.DefaultLabels
            : labels.GroupBy(value => value).OrderByDescending(group => group.Count()).ThenByDescending(group => group.Key == LabelMode.Always).First().Key;
        return config with
        {
            Settings = config.Settings with { AllFencesIntroduced = true, Appearance = config.Settings.Appearance with { IconSize = size, Labels = label } },
            Fences = config.Fences.Select(fence => fence with
            {
                IconSize = fence.IconSize == size ? null : fence.IconSize,
                Labels = fence.Labels == label ? null : fence.Labels,
            }).ToList(),
        };
    }
}

public sealed record Recipe
{
    public string Name { get; init; } = "";
    /// <summary>M41b: the card's emoji (not applied to the fence).</summary>
    public string? Emoji { get; init; }
    public OwnLook Look { get; init; } = new();
    public int? IconSize { get; init; }
    public LabelMode? Labels { get; init; }
    public Items.FenceLayout? Layout { get; init; }
    public OpenWith? OpenWith { get; init; }
    /// <summary>Downloads inbox: a folder panel in the fence shows Details, newest first (the App applies it to items.json).</summary>
    public bool Inbox { get; init; }
}

public static class Recipes
{
    public const int MaxNameLength = 40;

    public static IReadOnlyList<Recipe> BuiltIn { get; } =
    [
        new() { Name = "Game shelf", Emoji = "🎮", Look = new OwnLook { Theme = FenceTheme.Hud, TitleStyle = TitleStyle.Caps, Strength = 60 }, IconSize = 96, Labels = LabelMode.OnHover, OpenWith = Model.OpenWith.OneClick },
        new() { Name = "Work desk", Emoji = "💼", Look = new OwnLook { Theme = FenceTheme.LightMica, TitleStyle = TitleStyle.Clean, Spacing = Spacing.Compact }, IconSize = 32, Labels = LabelMode.Always, OpenWith = Model.OpenWith.DoubleClick },
        new() { Name = "Downloads inbox", Emoji = "📥", Look = new OwnLook { Theme = FenceTheme.Aurora, TitleStyle = TitleStyle.Clean }, Labels = LabelMode.Always, OpenWith = Model.OpenWith.DoubleClick, Inbox = true },
        new() { Name = "Minimal", Emoji = "◻", Look = new OwnLook { Theme = FenceTheme.Aurora, TitleStyle = TitleStyle.Caps, Strength = 10, TitleOnHover = true }, Labels = LabelMode.OnHover },
    ];

    public static IReadOnlyList<Recipe> All(NeoFencesConfig config) => [.. BuiltIn, .. config.Presets];

    /// <summary>One fence: the recipe's parts become the fence's own; parts the recipe has not stay.</summary>
    public static NeoFencesConfig Apply(NeoFencesConfig config, string fenceId, Recipe recipe)
    {
        var fence = Require(config, fenceId);
        return config.WithFence(fence with
        {
            Look = ConfigNormalizer.NormalizeLook(recipe.Look),
            IconSize = recipe.IconSize ?? fence.IconSize,
            Labels = recipe.Labels ?? fence.Labels,
            Layout = recipe.Layout ?? fence.Layout,
            OpenWith = recipe.OpenWith ?? fence.OpenWith,
        });
    }

    /// <summary>
    /// Every fence (null): the recipe becomes All fences' values and every fence follows them; some fences: each gets the
    /// recipe as its own (the others keep following). Places, sizes, items and layouts are never touched.
    /// </summary>
    public static NeoFencesConfig ApplyToAll(NeoFencesConfig config, Recipe recipe, IReadOnlyCollection<string>? onlyFenceIds)
    {
        if (onlyFenceIds is not null) return onlyFenceIds.Aggregate(config, (changed, fenceId) => Apply(changed, fenceId, recipe));
        var look = recipe.Look;
        var appearance = config.Settings.Appearance;
        appearance = appearance with
        {
            Theme = look.Theme ?? appearance.Theme,
            TitleStyle = look.TitleStyle ?? appearance.TitleStyle,
            ColourStyle = look.ColourStyle ?? appearance.ColourStyle,
            TitleAlign = look.TitleAlign ?? appearance.TitleAlign,
            TitleOnHover = look.TitleOnHover ?? appearance.TitleOnHover,
            Spacing = look.Spacing ?? appearance.Spacing,
            IconSize = recipe.IconSize ?? appearance.IconSize,
            Labels = recipe.Labels ?? appearance.Labels,
            TitleFont = look.TitleFont is { } font ? new TitleFont(font.Family ?? appearance.TitleFont.Family, font.Size ?? appearance.TitleFont.Size, font.Weight ?? appearance.TitleFont.Weight) : appearance.TitleFont,
        };
        if (look.Strength is { } strength) appearance = appearance.WithStrength(strength);
        var settings = config.Settings with { Appearance = appearance, OpenItemsWith = recipe.OpenWith ?? config.Settings.OpenItemsWith };
        var follow = Enum.GetValues<LookSetting>();
        return config with
        {
            Settings = settings,
            Fences = config.Fences.Select(fence => follow.Aggregate(fence, AllFences.ClearOwn) with { Layout = recipe.Layout ?? fence.Layout }).ToList(),
        };
    }

    /// <summary>What a recipe changes, one plain line each (the confirmations list them).</summary>
    public static IReadOnlyList<string> Changes(Recipe recipe)
    {
        var lines = new List<string>();
        var look = recipe.Look;
        if (look.Theme is { } theme) lines.Add("Theme → " + ThemeName(theme));
        if (look.Strength is { } strength) lines.Add($"Transparency → {strength} %");
        if (look.TitleStyle is { } style) lines.Add("Title style → " + style);
        if (look.TitleOnHover == true) lines.Add("Title bar → only on hover");
        if (look.Spacing is { } spacing) lines.Add("Spacing → " + spacing);
        if (recipe.IconSize is { } size) lines.Add($"Icon size → {size} px");
        if (recipe.Labels is { } labels) lines.Add(labels == LabelMode.Always ? "Names → always" : "Names → on hover");
        if (recipe.Layout is { } layout) lines.Add(layout == Items.FenceLayout.Free ? "Layout → Free" : "Layout → Grid");
        if (recipe.OpenWith is { } openWith) lines.Add(openWith == Model.OpenWith.OneClick ? "Open with → one click" : "Open with → double click");
        if (recipe.Inbox) lines.Add("A folder panel → Details, newest first");
        return lines;
    }

    public static string ThemeName(FenceTheme theme) => theme switch
    {
        FenceTheme.Aurora => "Aurora glass", FenceTheme.Hud => "Game HUD", FenceTheme.LightMica => "Light Mica", _ => theme.ToString(),
    };

    /// <summary>"Save as recipe…": what the fence shows now (its own values and what it follows), under a name and emoji.</summary>
    public static NeoFencesConfig Save(NeoFencesConfig config, string fenceId, string name, string? emoji)
    {
        if (NameProblem(name) is not null) return config;
        var fence = Require(config, fenceId);
        var all = config.Settings.Appearance;
        var own = fence.Look ?? new OwnLook();
        var recipe = new Recipe
        {
            Name = Clean(name),
            Emoji = Emoji.Normalize(emoji),
            Look = new OwnLook
            {
                Theme = own.Theme ?? all.Theme, TitleStyle = own.TitleStyle ?? all.TitleStyle, ColourStyle = own.ColourStyle ?? all.ColourStyle,
                Strength = own.Strength ?? all.StrengthDark, TitleFont = own.TitleFont, TitleAlign = own.TitleAlign ?? all.TitleAlign,
                TitleOnHover = own.TitleOnHover ?? all.TitleOnHover, Spacing = own.Spacing ?? all.Spacing,
            },
            IconSize = fence.IconSize ?? all.IconSize,
            Labels = fence.Labels ?? all.Labels,
            Layout = fence.Layout,
            OpenWith = fence.OpenWith ?? config.Settings.OpenItemsWith,
        };
        var recipes = config.Presets.ToList();
        var index = recipes.FindIndex(existing => string.Equals(existing.Name, recipe.Name, StringComparison.OrdinalIgnoreCase));
        if (index >= 0) recipes[index] = recipe;
        else recipes.Add(recipe);
        return config with { Presets = recipes };
    }

    // OpenWith when the recipe has them), Clean, Require: as in LookPresets, renamed.
}
