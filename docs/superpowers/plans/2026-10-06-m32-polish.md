# M32 — Polish (0.19.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every deferred minor of M31 and the Free-layout bug fixed in one patch release.

**Architecture:** Core gets the sticky GPU choice (`Widgets.StickyGpu`, used by both parsers and the Windows fallback; `SensorReading.GpuKey` carries the choice), the date line in the culture's order, and `Fahrenheit` written only when set. Shell keeps each source's last GPU, rents the copy buffer and holds HWiNFO's mutex. The App rebuilds the bars on every accent change, hides empty hint lines, holds the first-start notice back during a game, and stores a Free fence's cells once its window has laid out.

**Tech Stack:** .NET 10, C#, WPF, xUnit; PowerShell + UI Automation for the live check.

**Spec:** `docs/superpowers/specs/2026-10-06-polish-0.19.1-design.md` (approved 2026-10-06).

## How this plan is written

Built in a scratch worktree (`m32-proto`), checked headless against the user's running Afterburner, and replay-verified on
a fresh worktree of `main` at `82aea6a`: the tests patch alone fails to build (10 errors — the RED), the Core patch makes
697 tests pass, the App patch builds with 0 warnings, and the tree is identical to the prototype. Tasks 1–2 are
**patches to apply** (`git apply --whitespace=nowarn <file>`; if one does not apply, stop).

**One deviation from the spec, ruled here:** item 3's threshold is **2× and 1 GB more** (`Widgets.SwitchGpuMb = 1024`),
not 256 MB — with 256 MB the spec's own example (a card idling at 0 MB beside a built-in GPU holding a few hundred MB)
would still flip. Recorded in the ledger at Task 1.

## Global Constraints

- Hard rules stand; no new dependency; no config schema change.
- `"fahrenheit"` is written only when true; old items read as before.
- The HWiNFO mutex is `Global\HWiNFO_SM2_MUTEX`, waited for at most 20 ms; without it the copy is taken as before.
- Commits: single line, Conventional Commits, past tense, **no Co-Authored-By trailer**; secret scan before each commit.
- Version stays `0.19.0` until the release step; the release is 0.19.1.

## Review Focus

1. **Accent change timing**: WPF's `SystemColors.AccentColor*` updated before or after our `ImmersiveColorSet` handler —
   the second, deferred rebuild covers "after"; check that nothing else in the theme path runs twice (live AR1).
2. **Free cells at first layout**: a box whose shown tab is Free, a hidden Free tab, a window that loads rolled up or
   quick-hidden (columns 0) — cells stored only from real columns, never from a 1-column pre-layout (live AR2).
3. **Mutex handling**: HWiNFO holding its mutex for longer than 20 ms, an abandoned mutex, no access — never a hang or an
   unreleased mutex (code review; `Release` disposes on every path).
4. **Sticky choice across sources**: the Afterburner, HWiNFO and Windows keys are separate; a source that vanishes keeps
   its last key harmlessly (Core tests `StickyGpu_*`, `Afterburner_StaysOnThePreviousGpu_AndSaysWhichItIs`).
5. **The date line in other cultures**: a long date ending with the weekday is the only switch (Core test over six
   cultures).
